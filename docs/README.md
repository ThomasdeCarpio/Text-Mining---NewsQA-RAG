# Documentation map

Tài liệu đang dùng:

- `experiments.md`: test feature mới và dùng Evaluation Desk;
- `evaluation.md`: metric và cấu trúc kết quả;
- `evaluation_dataset.md`: chỉ dùng khi đổi corpus/ground truth;
- `benchmarking.md`: chạy thủ công một cấu hình;
- `architecture.md`, `database.md`, `ui.md`: kiến trúc và runtime.

`archive/` chứa slide, explainer và nội dung thuyết trình cũ. Chúng được giữ làm
tài liệu môn học nhưng không phải source of truth cho cấu trúc/code hiện tại.
